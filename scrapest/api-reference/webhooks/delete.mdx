---
title: "Delete Webhook"
api: "DELETE https://scrapest.duckdns.org/webhook"
---

Remove the webhook registered to your API key.

<ParamField header="x-api-key" type="string" required>
  Your unique API key.
</ParamField>

<RequestExample>
  ```bash curl
  curl -X DELETE https://scrapest.duckdns.org/webhook \
    -H "x-api-key: YOUR_API_KEY"
  ```

```javascript fetch
fetch("https://scrapest.duckdns.org/webhook", {
  method: "DELETE",
  headers: {
    "x-api-key": "YOUR_API_KEY",
  },
})
  .then((response) => response.json())
  .then((data) => console.log(data));
```

</RequestExample>

<ResponseExample>
  ```json Response
  {
    "message": "Webhook deleted successfully"
  }
  ```
</ResponseExample>
