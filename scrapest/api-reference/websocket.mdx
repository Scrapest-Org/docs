title: "WebSocket Stream"
description: "Stream live tweet events in real-time over a persistent WebSocket connection"
---

The Scrapest WebSocket endpoint delivers real-time tweet events for accounts you are tracking. Each message is a single `ResolvedTweet` object encoded as JSON.

## Connection

Connect to the WebSocket endpoint by passing your API key as the `x-api-key` header during the upgrade handshake.

```
wss://scrapest.duckdns.org/ws
```

<ParamField header="x-api-key" type="string" required>
  Your unique API key. The connection will be rejected with HTTP 401 if this is
  missing or invalid.
</ParamField>

### Code Examples

<CodeGroup>
```javascript JavaScript (Browser)
const ws = new WebSocket("wss://scrapest.duckdns.org/ws", {
  headers: { "x-api-key": "your-api-key" },
});

ws.onopen = () => console.log("Connected to Scrapest stream");
ws.onmessage = ({ data }) => {
const tweet = JSON.parse(data);
console.log(`[@${tweet.author.screen_name}]: ${tweet.text}`);
};
ws.onclose = () => console.log("Disconnected");
ws.onerror = (e) => console.error("WS error", e);

````

```javascript Node.js (ws)
import WebSocket from "ws";

const ws = new WebSocket("wss://scrapest.duckdns.org/ws", {
  headers: { "x-api-key": "your-api-key" },
});

ws.on("open", () => console.log("Connected"));
ws.on("message", (data) => {
  const tweet = JSON.parse(data.toString());
  console.log(`[@${tweet.author.screen_name}]: ${tweet.text}`);
});
ws.on("close", () => console.log("Disconnected"));
````

```python Python
import asyncio, json, websockets

async def stream():
    async with websockets.connect(
        "wss://scrapest.duckdns.org/ws",
        extra_headers={"x-api-key": "your-api-key"},
    ) as ws:
        async for message in ws:
            tweet = json.loads(message)
            print(f"@{tweet['author']['screen_name']}: {tweet['text']}")

asyncio.run(stream())
```

</CodeGroup>

## Keep-Alive

The server sends WebSocket **ping** frames every **30 seconds** to keep idle connections alive. If your client does not respond with a **pong** within 60 seconds, the connection will be terminated.

Most WebSocket libraries handle ping/pong automatically. If yours doesn't, send a `"ping"` text message and the server will respond with `"pong"`.

```javascript
// Browser clients — send a periodic ping if needed
setInterval(() => ws.send("ping"), 25_000);
```

## Events (Tweet Payload)

Every message you receive is a JSON-encoded `ResolvedTweet` object. The payload contains the full tweet and author information.

<ResponseField name="id" type="string">
  Unique tweet ID.
</ResponseField>

<ResponseField name="text" type="string">
  Full text of the tweet.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the tweet was created.
</ResponseField>

<ResponseField name="lang" type="string">
  BCP 47 language tag (e.g. `"en"`, `"fr"`).
</ResponseField>

<ResponseField name="favorite_count" type="number">
  Like count.
</ResponseField>
<ResponseField name="retweet_count" type="number">
  Retweet count.
</ResponseField>
<ResponseField name="reply_count" type="number">
  Reply count.
</ResponseField>
<ResponseField name="quote_count" type="number">
  Quote count.
</ResponseField>
<ResponseField name="bookmark_count" type="number">
  Bookmark count.
</ResponseField>

<ResponseField name="author" type="object" required>
  The account that posted the tweet.
  <Expandable title="author properties">
    <ResponseField name="id" type="string">
      Twitter user ID.
    </ResponseField>
    <ResponseField name="name" type="string">
      Display name.
    </ResponseField>
    <ResponseField name="screen_name" type="string">
      Username (without `@`).
    </ResponseField>
    <ResponseField name="profile_image_url" type="string">
      Profile picture URL.
    </ResponseField>
    <ResponseField name="verified" type="boolean">
      Legacy verified status.
    </ResponseField>
    <ResponseField name="is_blue_verified" type="boolean">
      Blue checkmark status.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="entities" type="object">
  Parsed entities extracted from the tweet text.
  <Expandable title="entities properties">
    <ResponseField name="urls" type="array">Expanded URLs found in the tweet.</ResponseField>
    <ResponseField name="hashtags" type="array">Hashtags (`{ text: string }[]`).</ResponseField>
    <ResponseField name="user_mentions" type="array">Mentioned users (`{ screen_name, id_str }[]`).</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="media" type="array">
  Attached media items (photos, videos, GIFs). Each item contains
  `media_url_https`, `type`, and an optional `video_info` block.
</ResponseField>

<ResponseField name="retweeted_tweet" type="boolean">
  `true` if this is a retweet.
</ResponseField>

<ResponseField name="retweeted" type="object">
  The original tweet object when `retweeted_tweet` is `true`.
</ResponseField>

<ResponseField name="quoted_tweet" type="object">
  The quoted tweet when this is a quote-tweet.
</ResponseField>

<ResponseField name="note_tweet_text" type="string">
  Extended text for long-form "Note Tweets".
</ResponseField>

<ResponseField name="in_reply_to_status_id" type="string">
  ID of the tweet being replied to.
</ResponseField>

<ResponseField name="conversation_id" type="string">
  ID of the root tweet in the conversation thread.
</ResponseField>

## Error Codes

| Code                  | Reason                                                             |
| --------------------- | ------------------------------------------------------------------ |
| `401 Unauthorized`    | `x-api-key` header is missing.                                     |
| `401 Invalid API Key` | The provided key does not exist.                                   |
| Connection closed     | Your session was idle for more than 60 seconds with no pong reply. |
