---
title: "List Tracked Users"
api: "GET https://scrapest.duckdns.org/tracked-users"
---

Retrieve a list of all currently tracked users.

_Note: This endpoint returns the list of users tracked by your API key._

<ParamField header="x-api-key" type="string" required>
  Your unique API key.
</ParamField>

<RequestExample>
  ```bash curl
  curl -X GET https://scrapest.duckdns.org/tracked-users \
  -H "x-api-key: YOUR_API_KEY"
  ```

```javascript fetch
fetch("https://scrapest.duckdns.org/tracked-users", {
  method: "GET",
  headers: {
    "x-api-key": "YOUR_API_KEY",
  },
})
  .then((response) => response.json())
  .then((data) => console.log(data));
```

</RequestExample>

<ResponseExample>
  ```json Response
  {
    "tracked_users": []
  }
  ```
</ResponseExample>
