---
title: "Authentication"
api: "POST https://webpush-production.up.railway.app/auth"
description: "Initiate the authentication flow via Telegram"
sidebarTitle: "Authentication"
---

This endpoint initiates the authentication process. You will receive a link to our Telegram bot, where you must complete the verification to obtain your API key.

<Note>
  The response contains an `auth_url`. You must visit this link and interact
  with the Telegram bot to finalize authentication.
</Note>

<ParamField body="none" type="object">
  No request body is required for this endpoint.
</ParamField>

<ResponseField name="status" type="string">
  The status of the request (e.g. "success").
</ResponseField>

<ResponseField name="message" type="string">
  Instructions on next steps.
</ResponseField>

<ResponseField name="data" type="object">
  Object containing authentication details.
  <Expandable title="properties">
    <ResponseField name="auth_url" type="string">
      The unique Telegram link to complete your authentication.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseExample>

```json 200 Success
{
  "status": "success",
  "message": "Please authenticate via Telegram",
  "data": {
    "auth_url": "https://t.me/YourBotName?start=723h23-234..."
  }
}
```

</ResponseExample>

<RequestExample>

```bash curl
curl -X POST https://webpush-production.up.railway.app/auth
```

```javascript fetch
fetch("https://webpush-production.up.railway.app/auth", {
  method: "POST",
})
  .then((response) => response.json())
  .then((data) => console.log(data));
```

</RequestExample>
